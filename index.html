Установка сервера

Запустите сервер за 6 шагов

Всё работает на Linux с Node.js 18+ и PostgreSQL 14+.

Установка PostgreSQL и создание базы данных

Настройте PostgreSQL и создайте базу, пользователя и расширение pgcrypto.

шаг 1
sudo -u postgres psql -c "CREATE EXTENSION IF NOT EXISTS "pgcrypto";"
sudo -u postgres psql -c "CREATE DATABASE messenger;"
sudo -u postgres psql -c "CREATE USER messenger_user WITH PASSWORD 'your_secure_password';"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE messenger TO messenger_user;"
sudo -u postgres psql -d messenger -c "GRANT ALL ON SCHEMA public TO messenger_user;"

Ubuntu / Debian: sudo apt install postgresql postgresql-contrib. На CentOS/RHEL дополнительно выполните: sudo dnf install postgresql-server postgresql-contrib && sudo postgresql-setup --initdb.

Установка зависимостей и файл окружения

Перейдите в папку сервера, установите зависимости и создайте файл .env из шаблона.

шаг 2
cd server
npm install
cp .env.example .env

Отредактируйте .env: укажите доступы к PostgreSQL, JWT_SECRET и опционально параметры LDAP/Active Directory.

Запуск миграций

Миграции создадут все необходимые таблицы: пользователей, каналы, сообщения, реакции, опросы и галочки прочтения.

шаг 3
npm run migrate

Миграции работают через knex. Перед первым запуском убедитесь, что пользователь PostgreSQL имеет права на схему public.

Запуск сервера

Для разработки используйте nodemon с горячей перезагрузкой, для продакшена — обычный старт.

шаг 4
npm run dev      # разработка (hot-reload)
npm start         # продакшн

Сервер будет доступен на http://localhost:3001. Откройте этот адрес в браузере и укажите его в клиенте.

Управление сервером через pm2

pm2 держит процесс в живых, перезапускает при сбоях и показывает логи.

шаг 5
pm2 start "npm start" --name messenger
pm2 restart messenger
pm2 logs messenger

Полезно добавить pm2-startup и pm2-save, чтобы сервер поднимался автоматически после перезагрузки.

Установка клиента (релиз)

Исходный код клиента не публикуется — приложение распространяется готовым установщиком из GitHub Releases.

шаг 6
# 1. Откройте раздел Releases репозитория на GitHub
# 2. Скачайте последний .exe и установите его
# 3. При входе укажите адрес сервера:
#    http://server-ip:3001

Адрес сервера хранится локально на каждом компьютере и меняется на странице входа (иконка настроек). Обновления доставляются автоматически с вашего сервера.

FAQ

Частые вопросы

Сколько стоит Точка.чат?

Нисколько. Мессенджер абсолютно бесплатный: без подписок, лицензионных платежей и ограничений по числу пользователей. Вы платите только за свой сервер.

Обязателен ли Active Directory?

Нет. LDAP/AD используется как основной источник аутентификации, но при недоступности сервера AD мессенджер автоматически переключается на локальную регистрацию в своей базе (bcrypt).

Какие требования к серверу?

Linux с установленными Node.js 18+ и PostgreSQL 14+. Для небольшой команды достаточно VPS от 2 ГБ RAM. Порт по умолчанию — 3001.

Как обновить приложение у пользователей?

Один раз выполните npm run pub patch|minor|major на своей машине: скрипт соберёт .exe, загрузит его и манифест latest.yml на сервер. Клиенты обновятся автоматически через electron-updater.

Код клиента открыт?

Нет. В публичном репозитории — серверная часть (server/) под лицензией MIT и готовый установщик .exe из релизов. Клиент распространяется как готовое приложение и поставляется без исходного кода.

Можно ли доработать под себя?

Серверную часть — да: она открыта, написана на Node.js и доступна для изменения и пересборки. Логика и интерфейс клиента в публичном доступе не публикуются.

Есть ли мобильный клиент?

Сейчас Точка.чат — нативное приложение для Windows. Клиент на Electron позволяет запускать интерфейс и в других настольных системах.
