Преимущества

Почему компании выбирают Точка.чат

01

Данные — только у вас

Мессенджер разворачивается на собственном сервере. Никаких облаков и третьих сторон — переписка и файлы не покидают периметр организации.

PostgreSQL, несколько файлов конфигурации и одна команда миграции. Готовый сервер за 15 минут — без сложных DevOps-пайплайнов.

Открытый стек

Electron + React + Node.js + PostgreSQL + Socket.IO — знакомые технологии, которые легко поддерживать и дорабатывать под свои задачи.

FAQ

Частые вопросы

Обязателен ли Active Directory?

Нет. LDAP/AD используется как основной источник аутентификации, но при недоступности сервера AD мессенджер автоматически переключается на локальную регистрацию в своей базе (bcrypt).

Какие требования к серверу?

Linux с установленными Node.js 18+ и PostgreSQL 14+. Для небольшой команды достаточно VPS от 2 ГБ RAM. Порт по умолчанию — 3001.

Как обновить приложение у пользователей?

Один раз выполните npm run pub patch|minor|major на своей машине: скрипт соберёт .exe, загрузит его и манифест latest.yml на сервер. Клиенты обновятся автоматически через electron-updater.

Код клиента открыт?

Нет. В публичном репозитории — серверная часть (server/) под лицензией MIT и готовый установщик .exe из релизов. Клиент распространяется как готовое приложение и поставляется без исходного кода.

Можно ли доработать под себя?

Серверную часть — да: она открыта, написана на Node.js и доступна для изменения и пересборки. Логика и интерфейс клиента в публичном доступе не публикуются.

Есть ли мобильный клиент?

Сейчас Точка.чат — нативное приложение для Windows. Клиент на Electron позволяет запускать интерфейс и в других настольных системах.
